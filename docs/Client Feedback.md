
## Client Feedback

Following the first iteration, feedback highlighted the need for better menu navigation and clearer order status visibility. As a result, features such as menu categorisation and order tracking were prioritised and implemented in iteration 2.

Additionally, the inclusion of delivery fee calculation and estimated delivery time improved the realism of the platform.


### Restaurant images
The client explained to the developers that they would like to differentiate between restaurants if all images are the same it looks as if its an error and makes it difficult to choose where to eat based on soley the name and menu.

### Menu Images
The client requested specifically that we implemented images for the individual items on the menu as they didn't know what they were ordering, this emphasises the importance of visual representation on menus.

### Navigation UI
The client noted that while the initial interface was functional, navigation between menus could be improved. This led to the introduction of menu categories to enhance usability.

### Order Tracking
The client emphasised the importance of transparency in the ordering process, which resulted in the implementation of the order tracking feature to display real-time updates.

### Delivery Times

The client wanted the site to be secure given it has sensitive information leading the developers to focus on this.
