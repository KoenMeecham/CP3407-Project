## Why These Tools Were Used

These tools were selected because they are widely used in modern web development and are well-suited for a team-based university project.

### Key Reasons

- **Fast development:** React + Vite allow rapid UI development  
- **Simple backend:** Express enables quick API creation  
- **Reliable database:** MySQL works well for structured data  
- **Cloud deployment:** AWS provides a real-world hosting environment  

### AWS Benefits

- **EC2** → full control over backend server configuration  
- **RDS** → automated backups, scalability, and easier database management  

These tools enabled efficient development, testing, and deployment of the FeedMe application.
