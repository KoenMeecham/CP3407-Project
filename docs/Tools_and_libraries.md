# Tools and Libraries

## Development Tools
- **GitHub** for version control and collaboration
- **GitHub Issues / Projects** for Agile task management
- **VS Code** for development
- **Node.js** runtime for backend and frontend tooling
- **npm** for dependency management

## Frontend Libraries
- **React** for building the user interface
- **React Router** for page routing
- **Vite** for frontend development and bundling

## Backend Libraries
- **Express** for API development
- **mysql2** for MySQL connectivity
- **dotenv** for environment variable management
- **cors** for cross-origin request handling

## Why These Tools Were Used
These tools were selected because they are lightweight, commonly used in web development, and suitable for a team-based university project. 
They allowed rapid development of a working prototype and iterative changes throughout the trimester.
