
# User story title: Order Confirmation
Other versions: As a customer, I want to receive an order confirmation so that I have a record of my purchase.

## Assumptions:
- The user has successfully completed checkout
- Order details are stored in the system
- Confirmation can be displayed on-screen without requiring email delivery in MVP
- A unique order reference or order ID can be generated
- Payment processing can be mocked if needed


## Description:   
The system will provide customers with an order confirmation after a successful purchase. The confirmation will display key details such as the order number, items ordered, 
total cost, and confirmation of purchase so the customer has a clear record of their transaction.


## Tasks
Tasks:   
Task 1 – Implement backend logic to retrieve completed order details, Estimated 0.5 days  
Task 2 – Create the order confirmation page UI, Estimated 0.5 days  
Task 3 – Display order number, purchased items, and total price, Estimated 0.5 days  
Task 4 – Add confirmation message and navigation options, Estimated 0.5 day
