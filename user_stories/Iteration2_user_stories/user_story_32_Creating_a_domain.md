## Assumptions:
- A hosting platform or server for the website already exists
- A domain name is available for purchase or registration
- The team has access to the DNS settings for the chosen domain
- The domain will be linked to the deployed website

## Description:
The system will use a custom domain name so that users can access the website through a professional and easy-to-remember web address 

## Tasks  
Task 1 - Research and choose an appropriate domain name, Estimation 0.25 days  
Task 2 - Register or purchase the domain through a domain provider, Estimation 0.5 days  
Task 3 - Configure DNS settings to point the domain to the deployed server or hosting service, Estimation 0.5 days  
Task 4 - Test that the domain correctly loads the website, Estimation 0.5 days  
Task 5 - Add final checks and ensure the domain is stable and accessible, Estimation 0.25 days
