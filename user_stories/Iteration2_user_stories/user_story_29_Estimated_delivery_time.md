## Assumptions:
- Order status and timestamps are already stored in the database
- Delivery time can be estimated based on order placement time and preparation status
- A static or rule-based estimate is acceptable (e.g. 30–45 mins from order placed)

## Description:
As a customer, I want to see an estimated delivery time so I can plan accordingly.
