## Assumptions:
- Restaurant data already includes cuisine or food category information
- Users can access the search feature from the main interface
- Cuisine filtering will initially use predefined cuisine types
- The feature only needs to support basic filtering in Iteration 2
- Performance will be acceptable for the expected class project data size


## Description: 
The system will allow users to filter by food e.g pasta, burgers etc.
